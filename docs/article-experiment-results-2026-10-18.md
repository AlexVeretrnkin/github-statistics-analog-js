# Результати експерименту від 18 жовтня 2026 року

Виконано перші чотири погоджені етапи: зафіксовано вхідні дані, збережено моделі та параметри, виконано rolling-origin порівняння і сформовано діагностику. Рукопис і робочі прогнози сайту не змінювалися.

## Дані й дизайн

За погодженням автора використано перевірений знімок локальної PostgreSQL-БД від 29 вересня 2026 року з даними до серпня 2026 включно. Це не production-знімок: перевірка доступної БД робочого GCP ingestion-сервісу виявила лише NPM-таблиці, без GitHub-таблиць. Хмарних записів або міграцій не виконано.

Знімок перевірено за SHA-256, безперервністю щоденних дат і відповідністю місячних сум. Вихідні файли скопійовано без зміни. Виключення початкових неповних місяців та початкових нульових спостережень зафіксовано окремо. Подальші нулі й аномальні значення не очищувалися.

- 6 рядів: NPM та GitHub для React, Angular і Vue.
- 24 спільні щомісячні точки прогнозування: вересень 2023 — серпень 2025; дата `YYYY-MM-01` є позначенням завершеного місяця, інформація доступна на його кінець.
- Expanding window, щонайменше 36 навчальних місяців; фактичні початки навчання залежать від ряду.
- 5 моделей: SARIMA, ETS, Prophet, naïve, seasonal naïve; спільне перетворення log1p.
- Оцінка прогнозу саме на 1, 3, 6 та 12 місяців уперед; усі моделі порівнюються на тих самих спостереженнях.
- 720 історичних навчань і 30 окремих навчань на всій історії, разом 750 збережених моделей.
- 120 рядків підсумкових метрик, 9 360 прогнозних рядків, 6 панелей залишків у PNG та векторному PDF.

Це ретроспективна перевірка на одному знімку даних. Історичні GitHub-значення можуть переглядатися джерелом, тому результати не відтворюють точний набір інформації, який реально був доступний у минулому.

## Найменша RMSE за горизонтами

| Ряд | 1 місяць | 3 місяці | 6 місяців | 12 місяців |
| --- | --- | --- | --- | --- |
| NPM React | Naïve | ETS | SARIMA | SARIMA |
| NPM Angular | ETS | ETS | ETS | SARIMA |
| NPM Vue | Naïve | Naïve | Naïve | SARIMA |
| GitHub React | SARIMA | Prophet | Prophet | Prophet |
| GitHub Angular | ETS | Prophet | Prophet | Prophet |
| GitHub Vue | ETS | ETS | ETS | ETS |

Це описове ранжування за 24 моментами прогнозування, без перевірки статистичної значущості різниць. Переможці визначені після спостереження результатів; це не незалежна оцінка вже налаштованої політики вибору моделі. У порівнянні зі старою таблицею змінилися і дані, і періоди оцінки, тому зміни не можна приписувати лише rolling-origin дизайну.

## Деталі для горизонту 12 місяців

| Ряд | Модель | RMSE у вихідних одиницях | WAPE | Покриття 80% | Покриття 95% |
| --- | --- | ---: | ---: | ---: | ---: |
| NPM React | SARIMA | 112 244 574 | 28.94% | 100.00% | 100.00% |
| NPM Angular | SARIMA | 2 292 973 | 10.43% | 100.00% | 100.00% |
| NPM Vue | SARIMA | 11 825 553 | 31.79% | 83.33% | 100.00% |
| GitHub React | Prophet | 309.71 | 19.39% | 87.50% | 95.83% |
| GitHub Angular | Prophet | 130.16 | 32.72% | 62.50% | 79.17% |
| GitHub Vue | ETS | 163.59 | 37.16% | 100.00% | 100.00% |

Точні значення — у `accuracy.csv`; табличні числа тут округлено. Кожне покриття спирається на 24 прогнози, і крок становить 4.17 процентного пункту. Помилки багатокрокових прогнозів залежні, тому ці частки не є точними гарантіями майбутнього покриття.

Високе покриття саме по собі не означає якісні інтервали. Для SARIMA NPM React середня ширина 80% інтервалу на горизонті 12 місяців становить приблизно **7.80 млрд завантажень**. Для ETS GitHub Vue — приблизно **24 976 зірок**. Тому поряд із покриттям збережено ширину та interval score. Для Prophet GitHub Angular номінальні 80% і 95% інтервали мають лише 62.5% і 79.17% покриття відповідно.

## Параметри та залишки

Для кожного навчання збережено об'єкт RDS, коефіцієнти, початкові стани ETS, специфікацію, налаштування та повідомлення оптимізатора. Для SARIMA наведено стандартні похибки та умовні асимптотичні Wald-інтервали коефіцієнтів. Вони не враховують невизначеність вибору структури. Для ETS і Prophet довірчі інтервали параметрів не обчислювалися; прогнозні інтервали не видаються за інтервали параметрів.

Діагностику отримано з тих самих об'єктів, що створюють прогнози. Для повної історії SARIMA NPM React має Ljung–Box p≈0.00000253, а SARIMA NPM Angular — p≈0.0428. Отже, найменша прогнозна RMSE не означає відсутності залишкової залежності. Для ETS і Prophet p-values позначені як дослідницькі, без валідованого коригування ефективних ступенів свободи; повні налаштування наведено в `diagnostics.csv`.

В окремих рядах присутні сильні ранні або внутрішні аномалії. У цьому експерименті вони збережені. Під час підготовки статті потрібно обговорити їхній вплив на оцінки й ширину інтервалів, не змінюючи постфактум основний протокол під бажаного переможця.

## Перевірки

- Усі 750 навчань завершилися успішно, збережених warnings або повідомлень про fallback немає.
- Усі 576 груп «ряд × момент прогнозування × горизонт» повні; жоден момент не вилучено з парного порівняння через збій.
- Перевірено вхідні спостереження всіх збережених моделей і часову межу навчання.
- Незалежно перераховано всі 120 рядків підсумкових метрик із числових прогнозів.
- Повторно отримано всі 30 прогнозів повної історії зі збережених RDS без нового навчання; значення відтворено.
- Відновлення запуску з контрольних точок залишило predictions, parameters, accuracy та diagnostics побайтово незмінними.
- Тести на контрольному ряді перевірили визначення naïve/seasonal naïve, відхилення нечислових прогнозів, формули похибок та interval score, seed і RDS replay.
- Контрольні суми пакета перевірено. Це перевірка в поточному середовищі, не підтвердження незалежного повторного навчання всього експерименту на іншій платформі.
